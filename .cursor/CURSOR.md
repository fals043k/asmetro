# Project Preferences

## Структура проекта
- Файлы header.html и footer.html это блоки, они будут повторяться на каждой странице. Поэтому мы прописываем их в отдельных файлах html и затем через js вставляем на каждую страницу
- Каждому пункту новигации в шапке соответствует отдельная страница html и отдельный подключенный одноименный файл css и js. Например home.html, home.css, home.js 
- К каждой странице должны быть подключены reset.css и global.css 


## Самые важные правила, сначала они потом все остальное. Высочайший приоритет
- Когда пишешь код, будь на 100% уверен что не ломаешь уже написанный код
- За основу написания кода, структуры и нейминга бери примеры из папки STYLE_GUIDE.md
- Каждая страница должна быть адаптивной к изменению ширины экрана. 
- Страница не должна ломаться при открытии ее с телефонов, планшетов, компьютеров. 
- Страница не должна ломаться при открытии ее в разных браузерах
- Пиши, используя стиль уже написанного кода, в других файлах проекта. Все должно быть написано в одном стиле!
- Внимательно рассматривай макет, получаемый результат должен в точности соответствовать ему.
- Всегда бери картинки из папки img и используй их в соответствии с макетом. 
- Для каждой страницы используй новый файл html и одноименный файл css

## Code Style
- Использовать современные стандарты (ES6+ для JavaScript)
- Следовать принципам чистого кода
- Добавлять комментарии только для сложной логики
- За основу написания кода бери примеры из папки STYLE_GUIDE.md

## Development
- Всегда проверять существующие файлы перед созданием новых
- Приоритет: читаемость > краткость
- Избегать избыточного кодирования


## HTML
- Всегда используй семантические HTML5 теги (header, nav, main, section, article, footer)
- Всегда указывай lang="ru" в теге html
- Всегда добавляй meta viewport для адаптивности
- Используй валидный HTML5
- Встроенные стили запрещены - все стили в отдельном CSS файле
- Используй понятные классы с BEM-подобной структурой (блок__элемент--модификатор)

## CSS
- Используй современные CSS техники: Flexbox, Grid, CSS Variables
- Цвета пиши в формате #ffffff 
- Всегда делай адаптивный дизайн 
- Используй осмысленные имена классов
- Группируй связанные стили вместе
- Комментарии добавляй только при необходимости
